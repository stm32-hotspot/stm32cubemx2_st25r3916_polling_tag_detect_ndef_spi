# Release Notes for <mark>stm32cubemx2_st25r3916_polling_tag_detect_ndef_spi</mark>

# Purpose

This example demonstrates how to use the ST25R3916 part driver with STM32CubeMX2 for polling tag detect and NDEF handling over SPI.

Initial release of the ST25R3916 polling_tag_detect_ndef_spi example for STM32CubeMX2.

No limitation raised for this example.

## Dependencies

Configuration and code generation features require STM32CubeMX2 >= 1.1.0.
